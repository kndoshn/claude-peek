# claude-peek

Claude Code の非公式な mod です。会話の横で物事を覗き、必要な部分だけを Claude に渡せます。
`/peek` でファイル、フォルダーのツリー、Git の状態と履歴、コマンドの出力を会話の横のパネルに開き、マウスで範囲を選んで **選択を引用** を押すと、出どころ
（`src/a.ts:118-125`）を付けた引用として入力欄に入ります。見たものは会話に入らず、引用した部分だけが
Claude に渡ります。別のタブもエディタもブラウザも要りません。

[English](README.md)

## インストール

Claude Code のターミナルのセッションで、入力欄に次を入力します。

```
/plugin install peek --marketplace kndoshn/claude-peek
```

marketplace の追加を `y` で承認し、スコープを選びます（先頭がユーザーのスコープです）。

シェルからは次のとおりです。

```
claude plugin install peek --marketplace kndoshn/claude-peek
```

`/plugin` が動かないデスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に
`kndoshn/claude-peek` を入れてから Add plugin を選びます。

peek は hooks module（mod）なので、それを読み込める Claude Code が要ります。Claude Code 2.1.316 で
動作を確かめています。引用はマウスの選択範囲を読むので、フルスクリーンのターミナルで使います。
パネルは 110 桁以上でトランスクリプトの横に 100 桁の幅で（端末の 45% まで。ドラッグで変えた幅が
優先されます）、それより狭いと入力欄の上に、画面の余裕の範囲で中身の高さに合わせて表示されます。
dark 系のテーマでは、パネルの背景を会話の欄と同じ端末の背景にします。ANSI 系のテーマでも明るい文字が
読みやすいようにするためです。

## 使い方

| 入力 | peek の動き |
| --- | --- |
| `/peek src/a.ts` | そのファイルを開く。作業ディレクトリからの相対パス、`~/...`、絶対パスのどれでもよい |
| `/peek src/a.ts:120` や `:120-130` | ソースをその行で開き、印を付けてそこまで送る |
| `/peek docs` | フォルダーのツリーを表示する |
| `/peek reg` | 名前の一部にいちばん合うものを開く。会話に出たファイル、プロジェクトのファイルとフォルダー、ghq の repo の順 |
| `/peek git` | リポジトリの状態と履歴を表示する |
| `/peek !ls -la` | コマンドをご自身のシェルで実行し、出力を表示する |
| `/peek` | パネルを前の場所で開き直す。初めてなら、作業ディレクトリのツリー |
| `/md [パスか名前]` | Markdown だけを対象にした同じ操作。名前なしなら、Claude が出したいちばん新しい `.md` |
| `/peek re` と入力中 | 合うファイル・フォルダー・repo を、その上のフォルダーを添えて補完の候補に出す |
| `/peek !g` と入力中 | 前に実行したコマンドのうち、そう始まるものを補完の候補に出す |
| 返答が `.md` に触れた | 入力欄の上に **開く: docs/plan.md** を出す。**×** で消える |

Markdown は整形して表示し、ほかのテキストファイルは行番号と言語ごとの色分けを付けたソースで表示します。
バイナリのファイルと 4 MiB を超えるファイルは開きません。パネルの先頭には、ファイル名・行数・表示の
種類を出します。長すぎるファイルは途中まで表示し、そのことを先頭に示します。ファイルは 1 秒ごとに
確かめていて、ディスク上で変わると（Claude・エディタ・スクリプトのどれが変えても）描き直します。
ディスクから消えたファイルは、削除されたことを示したまま表示を残します。ほかの Markdown ファイルへの
相対リンク（`[setup](../setup.md)`、`[setup][ref]`、`[a](<my notes.md>)`）をクリックすると、その
ファイルをパネルで開きます。front matter は YAML のブロックとして表示します。

フォルダーはツリーで表示し、先頭にパスと、git のリポジトリならブランチを出します。最初は小さいフォルダー
から 200 行まで開きます。フォルダーをクリックすると開閉し、ファイルをクリックするとファイルの表示で
開きます（**← 戻る** でツリーに戻ります）。100 件を超えるフォルダーは、最初の 100 件と、残りを出す行を
表示します。git で変わったファイルには `M`・`A`・`D`・`R`・`?`（未追跡）、それを含むフォルダーには `•` を
付けます。git が無視するものは薄く表示し、最初は閉じたままにします。`.git` は出しません。表示している間は
5 秒ごとに読み直し、Claude がコマンドを実行したりファイルを編集したりしたときにも読み直します。

`/peek git` は、作業ディレクトリのリポジトリを表示します。ブランチと upstream との先行・遅れのコミット数、
stash の数、ステージ済み・未ステージ・未追跡のファイル（クリックで開きます）、`git log --graph` と同じ形の
履歴 40 件です。コミットをクリックすると、作者・日時・メッセージ・変更したファイルと、ファイルごとの差分を
表示します（マージは最初の親との差分）。**← 戻る** で履歴に戻ります。作業中の変更の差分は、Claude Code の
組み込みの `/diff` に任せます。git は index のロックを取らずに動かすので（`GIT_OPTIONAL_LOCKS=0`）、Claude が
動かす git の邪魔をしません。表示している間は 5 秒ごとに状態を確かめ、状態が変わったときと、Claude が
コマンドを実行したりファイルを編集したりしたときに、全体を読み直します。

`/peek !コマンド` は、ご自身のシェル（`$SHELL`、なければ `/bin/sh`）を対話モードで起動し、作業
ディレクトリで実行します。エイリアスや関数もそのまま使えます。出力はパネルに出し、`!` モードと違って
会話には入りません。必要な行だけを引用してください。先頭にコマンドと終了コードを出し、標準エラー出力は
分けて出します。色などのエスケープシーケンスは取り除きます。30 秒で止めます（設定で変えられます）。
`tail -f` のように終わらないコマンドには向きません。`!` モードと同じく、Claude のサンドボックスの外で
動きます。peek は実行するときに `PEEK=1` を渡すので、シェルの設定で Claude Code の中ではエイリアスを
切っている場合（`CLAUDECODE` を見る書き方）、`if [[ -z "${CLAUDECODE:-}" || -n "${PEEK:-}" ]]` の
ように直せば、これらのコマンドではエイリアスが効きます。

パネルを開いている間は、入力欄の上に次のボタンが並びます。

- **ファイル** · **ツリー** · **Git** · **コマンド**: 表示を切り替えます。それぞれの表示は前の内容を覚えています。まだ開いて
  いない表示は、開き方を案内します。

- **選択を引用**: パネルで選んだ範囲を、入力中の文の後ろに足します。

  ```
  docs/plan.md:12-14
  > The first step.
  >
  > - see the setup guide
  ```

  行番号は、選んだテキストをファイルの中から探して付けます。ソース表示から選んで行番号が一緒に
  入ったときは、その行番号を使います。見つからないとき（画像の代替テキストなど）は、ファイル名
  だけを付けます。会話の中で選んだ範囲は、見出しなしで引用します。
- **ソース** / **整形**（Markdown）: 整形した表示と、行番号付きの書いたままの表示を切り替えます。
- **変更 +3 −1**: 前回の送信からファイルがどう変わったかを差分で表示します。ファイルが変わると
  現れ、次に送信すると数え直します。**変更を閉じる** でファイルの表示に戻ります。変わった行が
  1000 行ほどを超えると、変わった部分をまとめて置き換えたものとして表示します。
- **@パス**: ファイルを `@` 付きで入力欄に足し、Claude に読ませます。
- **ツリーを引用**（ツリー）: `tree` と同じ形のツリーを、フォルダーを見出しにしたコードブロックで足します。
  **@パス** は最後にクリックしたフォルダー（なければ表示中のフォルダー）を `@` 付きで足し、**コピー** は
  ツリーをクリップボードに入れます。
- **コミットを入れる**（Git で開いたコミット）: ハッシュと件名を足します。**更新** は Git をすぐに読み直します。
- **出力を引用**（コマンド）: 出力全体を、コマンドを見出しにしたコードブロックで足します。
- **再実行**（コマンド）: コマンドを、前と同じフォルダーでもう一度実行します。
- **コピー**（コマンド）: 出力をクリップボードに入れます。
- **← 戻る**: リンクをたどる前のファイルに戻ります。
- **閉じる**: パネルを閉じます。パネルの閉じるマークでも閉じます。Esc でも閉じます（パネルに
  フォーカスがあるときか、入力欄が空で Claude が待機中のとき）。

ボタンはクリックするか、この行にフォーカスを移して（ctrl+x tab かクリック）文字のキーで押せます。
`q` 引用、`s` ソース、`d` 変更、`a` @パス、`t` ツリーか出力を引用、`r` 再実行か更新、`c` コピー、`b` 戻る、`o` 提案された
ファイルを開く、です。

プロジェクトのファイルは `git ls-files` の一覧（追跡中と未追跡のもの。無視するものは除く）から、git の
リポジトリの外では `fd` があればその一覧から探します。repo は、ghq があれば `ghq list` から探します。

## 設定

`/config` に peek の行が 3 つあります。

| 設定 | 値 | 既定値 |
| --- | --- | --- |
| Language | `auto`、`en`、`ja` | `auto`: Claude Code の `language` の設定、次にロケール（`LC_ALL`・`LC_MESSAGES`・`LANG`）、どれもなければ英語 |
| Command time limit (seconds) | 1〜600 | 30 |
| Short commands /tree and /git | オン、オフ | オフ。ほかのプラグインやスキルが使う名前のため。オンにすると `/tree [フォルダー]` と `/git` が `/peek [フォルダー]` と `/peek git` と同じ動きをする |

## 開発

設計は [docs/design.md](docs/design.md) にあります。

```
claude --plugin-dir .            # このフォルダを読み込んでセッションを始める。保存すると読み直す
claude plugin test .             # tests/*.test.ts(x) を実行する
claude plugin validate .         # マニフェストと hooks module を検査する
```

| ファイル | 中身 |
| --- | --- |
| `hooks/register.tsx` | hooks module。コマンドと、イベントとほかのファイルのつなぎ |
| `hooks/nav.ts` | パネル。開いているか、どの表示か、表示をまたいだ戻る |
| `hooks/views/*.ts` | 表示ごとの状態と、状態を変える操作 |
| `hooks/ui/*.tsx` | パネル、入力欄の上の帯、表示ごとの描画 |
| `hooks/find.ts` | ファイルを探して読む |
| `hooks/prompt.ts` | 入力欄への引用と `@` の追加 |
| `hooks/run.ts` | index のロックを取らない git の実行、時計、表示を読み直す間隔 |
| `hooks/messages.ts` | 英語と日本語のメッセージと、どちらを使うか |
| `hooks/pure/*.ts` | 純粋な関数（パス、引数の解析、引用、Markdown、行の差分、端末の出力、ツリー、git の出力） |
| `tests/*.test.tsx` | エンジンを相手にした mod のテスト。`tests/support.tsx` がその下のエンジン |
| `tests/units.test.ts` | 純粋な関数のテスト |
