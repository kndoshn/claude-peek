# md-review

Claude が書いた Markdown を、セッションから離れずにレビューするための Claude Code の mod です。
`/md` でファイルをチャットの横のパネルに表示します。マウスで範囲を選んで **選択を引用** を押すと、
ファイル名と行番号の付いた引用として入力欄に入ります。別のタブもエディタもブラウザも要りません。

[English](README.md)

## インストール

Claude Code のターミナルのセッションで、入力欄に次を入力します。

```
/plugin install md-review --marketplace kndoshn/md-review
```

marketplace の追加を `y` で承認し、スコープを選びます（先頭がユーザーのスコープです）。

シェルからは次のとおりです。

```
claude plugin install md-review --marketplace kndoshn/md-review
```

`/plugin` が動かないデスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に
`kndoshn/md-review` を入れてから Add plugin を選びます。

md-review は hooks module（mod）なので、それを読み込める Claude Code が要ります。Claude Code
2.1.316 で動作を確かめています。引用はマウスの選択範囲を読むので、フルスクリーンのターミナルで
使います。パネルは 110 桁以上でトランスクリプトの横に 100 桁の幅で（端末の 45% まで。ドラッグで
変えた幅が優先されます）、それより狭いと入力欄の上に、画面の余裕の範囲でファイルの高さに合わせて
表示されます。dark 系のテーマでは、パネルの背景を会話の欄と同じ端末の背景にします。ANSI 系のテーマ
でも明るい文字が読みやすいようにするためです。

## 使い方

| 操作 | md-review の動き |
| --- | --- |
| `/md` | 直近の会話で Claude が書いた・編集した・読んだ・名前を出した `.md` のうち、いちばん新しいものを開く |
| `/md docs/plan.md` | そのファイルを開く。作業ディレクトリからの相対パス、`~/...`、絶対パスのどれでもよい |
| `/md plan` | 名前の一部にいちばん合うファイルを開く。会話に出たファイルが先、次にプロジェクトのファイル |
| `/md pl` と入力中 | 合う Markdown ファイルを補完の候補に出す |
| 返答が `.md` に触れた | 入力欄の上に **開く: docs/plan.md** を出す。**×** で消える |

パネルの先頭には、ファイル名・行数・表示の種類を出します。ファイルは 1 秒ごとに確かめていて、
ディスク上で変わると（Claude・エディタ・スクリプトのどれが変えても）描き直します。ディスクから
消えたファイルは、削除されたことを示したまま表示を残します。ほかの Markdown ファイルへの相対
リンク（`[setup](../setup.md)`）をクリックすると、そのファイルをパネルで開きます。front matter は
YAML のブロックとして表示します。長すぎるファイルは途中まで表示し、そのことを先頭に示します。

ファイルを開いている間は、入力欄の上に次のボタンが並びます。

- **選択を引用**: パネルで選んだ範囲を、入力中の文の後ろに足します。

  ```
  docs/plan.md:12-14
  > The first step.
  >
  > - see the setup guide
  ```

  行番号は、選んだテキストをファイルの中から探して付けます。ソース表示から選んで行番号が一緒に
  入ったときは、その行番号を使います。見つからないとき（画像の代替テキストなど）は、ファイル名
  だけを付けます。
- **ソース** / **整形**: 整形した表示と、行番号付きの書いたままの表示を切り替えます。
- **変更 +3 −1**: 前回の送信からファイルがどう変わったかを差分で表示します。ファイルが変わると
  現れ、次に送信すると数え直します。**変更を閉じる** でファイルの表示に戻ります。変わった行が
  1000 行ほどを超えると、変わった部分をまとめて置き換えたものとして表示します。
- **← 戻る**: リンクをたどる前のファイルに戻ります。
- **閉じる**: パネルを閉じます。パネルの閉じるマークでも閉じます。Esc でも閉じます（パネルに
  フォーカスがあるときか、入力欄が空で Claude が待機中のとき）。

ボタンはクリックするか、この行にフォーカスを移して（ctrl+x tab かクリック）文字のキーで押せます。
`q` 引用、`s` ソース、`d` 変更、`b` 戻る、`o` 提案されたファイルを開く、です。

開けるのは `.md` と `.markdown` だけです。プロジェクトのファイルは `git ls-files` の一覧（追跡中と
未追跡のもの。無視するものは除く）から、git のリポジトリの外では `fd` があればその一覧から探します。

## 設定

`/config` に md-review の行が 1 つあります。

| 設定 | 値 | 既定値 |
| --- | --- | --- |
| Language | `auto`、`en`、`ja` | `auto`: Claude Code の `language` の設定、次にロケール（`LC_ALL`・`LC_MESSAGES`・`LANG`）、どれもなければ英語 |

## 開発

```
claude --plugin-dir .            # このフォルダを読み込んでセッションを始める。保存すると読み直す
claude plugin test .             # tests/*.test.tsx を実行する
claude plugin validate .         # マニフェストと hooks module を検査する
```

| ファイル | 中身 |
| --- | --- |
| `hooks/register.tsx` | hooks module。イベントとほかのファイルをつなぐ |
| `hooks/doc.ts` | 表示中のファイルと提案中のファイル。その状態と、状態を変える操作 |
| `hooks/files.ts` | Markdown ファイルを探して読む |
| `hooks/ui.tsx` | パネルと入力欄の上の帯 |
| `hooks/messages.ts` | 英語と日本語のメッセージと、どちらを使うか |
| `hooks/paths.ts`・`quote.ts`・`markdown.ts`・`diff.ts` | 純粋な関数（パス、引用、Markdown の下ごしらえ、行の差分） |
| `tests/md-review.test.tsx` | エンジンを相手にした mod のテスト |
| `tests/units.test.ts` | 純粋な関数のテスト |
