# claude-peek

Claude Code の会話の横で、ファイル・フォルダー・Git・コマンドの出力を覗き、必要な部分だけを出どころ付きで
入力欄に引用できます。

[English](README.md)

`/peek` で会話の横にパネルを開き、マウスで範囲を選んで **選択を引用** を押すと、入力欄に次のように入ります。

```
src/parser.ts:118-120
> const end = text.lastIndexOf('\n')
> if (end < 0) return text
> return text.slice(0, end)
```

見たものは会話に入らず、引用した部分だけが Claude に渡ります。別のタブもエディタもブラウザも要りません。
peek は Claude Code の非公式な mod です。

| 表示 | 開き方 | 中身 |
| --- | --- | --- |
| ファイル | `/peek src/a.ts`、`/md plan` | Markdown は整形して、ほかのテキストは行番号付きで表示。前回の送信からの変更も見られる |
| ツリー | `/peek docs` | フォルダーを git の印付きのツリーで表示。クリックでフォルダーを開閉し、ファイルを開く |
| Git | `/peek git` | ブランチ・状態・履歴のグラフ。コミットをクリックすると差分 |
| コマンド | `/peek !ls -la` | ご自身のシェルで実行したコマンドの出力 |

## 必要なもの

- hooks module（mod）を読み込める Claude Code。Claude Code 2.1.316 で動作を確かめています
- 引用には、フルスクリーンのターミナル。マウスの選択範囲を読むためです
- あれば使うもの: git（印、Git の表示、プロジェクトのファイル）、ghq（repo を開く）、fd（git の外のファイル）。
  なければ、その部分を出さずに動きます

## インストール

Claude Code のターミナルのセッションで、入力欄に次を入力します。

```
/plugin install peek --marketplace kndoshn/claude-peek
```

marketplace の追加を `y` で承認し、スコープを選びます（先頭がユーザーのスコープです）。

シェルからは次のとおりです。

```
claude plugin install peek --marketplace kndoshn/claude-peek
```

`/plugin` が動かないデスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に
`kndoshn/claude-peek` を入れてから Add plugin を選びます。

## 使い方

### コマンド

| 入力 | peek の動き |
| --- | --- |
| `/peek src/a.ts` | ファイルを開く。作業ディレクトリからの相対パス、`~/...`、絶対パスのどれでもよい |
| `/peek src/a.ts:120` や `:120-130` | ソースをその行で開き、印を付けてそこまで送る |
| `/peek docs` | フォルダーのツリーを表示する。`/peek ~` ならホーム |
| `/peek reg` | 打った文字を名前かパスにそのまま含むもののうち、いちばん合うものを開く（下を参照） |
| `/peek git` | リポジトリの状態と履歴を表示する |
| `/peek !ls -la` | コマンドをご自身のシェルで実行し、出力を表示する |
| `/peek` | パネルを前の場所で開き直す。初めてなら、作業ディレクトリのツリー |
| `/md [パスか名前]` | Markdown だけを対象にした同じ操作。名前なしなら、Claude が出したいちばん新しい `.md` |

名前は、会話に出たファイル、プロジェクトのファイルとフォルダー、ghq の repo の順に探します。プロジェクトの
ファイルは `git ls-files` の一覧（追跡中と未追跡のもの。無視するものは除く）で、git のリポジトリの外では
`fd` の一覧です。コマンドで開くのは、打った文字をそのまま含むものだけです。文字が順に現れるだけのものは、
補完の候補にだけ出します。

Claude の返答が `hooks/find.ts:89` のように行を示すと、`/peek` はその行付きの候補を出し、名前でいちばん合う
ものがそれならその行で開きます。打った行があればそちらを使い、パスをそのまま打てば先頭から開きます。`/md` は
整形して読むためのものなので、行を付けずに出します。

入力中は、`/peek re` で合うファイル・フォルダー・repo を、その上のフォルダーを添えて補完の候補に出し、
`/peek !g` で前に実行したコマンドのうちそう始まるものを出します。Claude の返答が `.md` に触れるか、
`src/a.ts:118-120` のようにファイルの行を示すと、入力欄の上に **開く: docs/plan.md** や
**開く: src/a.ts:118-120** を出し、押すとその行で開きます。**×** で消えます。

### ファイルの表示

- Markdown は整形して表示し、ほかのテキストファイルは行番号と言語ごとの色分けを付けたソースで表示します。
  Markdown は **ソース** で書いたままの表示に切り替えられます
- 先頭には、ファイル名・行数・表示の種類を出します。長すぎるファイルは途中まで表示し、そのことを先頭に
  示します。バイナリのファイルと 4 MiB を超えるファイルは開きません
- ファイルは 1 秒ごとに確かめていて、ディスク上で変わると、誰が変えても描き直します。ディスクから消えた
  ファイルは、削除されたことを示したまま表示を残します。開いた後でバイナリになったり 4 MiB を超えたり
  したファイルは、それまでの表示を残します。帯や `/peek` でこのファイルに戻ったときも同じです
- **変更 +3 −1** で、前回の送信からファイルがどう変わったかを差分で表示します。ファイルが変わると現れ、
  次に送信すると数え直します。変わった行が 1000 行ほどを超えると、変わった部分をまとめて置き換えたもの
  として表示します
- ファイルやフォルダーへの相対リンク（`[setup](../setup.md)`、`[setup][ref]`、`[a](<my notes.md>)`、
  `[parser](../src/a.ts#L10-L20)`、`[src](../src/)`）をクリックすると、パネルで開きます。ファイルはファイル
  の表示で、GitHub の行の指定（`#L10`、`#L10-L20`）があればその行で開き、フォルダーはツリーで開きます。
  **← 戻る** で戻ります
- front matter は YAML のブロックとして表示します。先頭に BOM があっても、改行が CRLF でも見つけます
- 制御文字はその記号（エスケープは `␛`、改ページは `␌`）で表示するので、色の付いたログも開けます。
  ファイル名や Git の表示でも同じです

### ツリーの表示

- 先頭に、フォルダーのパスと、git のリポジトリならブランチを出します
- 最初は小さいフォルダーから 200 行まで開きます。フォルダーをクリックすると開閉し、ファイルをクリック
  するとファイルの表示で開きます（**← 戻る** でツリーに戻ります）
- 100 件を超えるフォルダーは、最初の 100 件と、残りを出す行を表示します
- git で変わったファイルには `M`・`A`・`D`・`R`・`?`（未追跡）、それを含むフォルダーには `•` を付けます。
  git が無視するものは薄く表示し、最初は閉じたままにします。`.git` は出しません
- シンボリックリンクは、たどった先の種類で表示します。フォルダーへのリンクは、最初は開かず、クリックで
  開けます
- 表示している間は 5 秒ごとに git の状態と開いているフォルダーを確かめ、どちらかが変わったときと、
  Claude がコマンドを実行したりファイルを編集したりしたときに、全体を読み直します

### Git の表示

- `/peek git` は、作業ディレクトリのリポジトリを表示します。ブランチと upstream との先行・遅れのコミット数、
  stash の数、ステージ済み・未ステージ・未追跡のファイルです。ファイルはクリックで開き、フォルダーは
  ツリーで開きます
- 履歴は `git log --graph` と同じ形で 40 件出します。コミットをクリックすると、作者・日時・メッセージ・
  変更したファイルと、ファイルごとの差分を表示します（マージは最初の親との差分）
- 作業中の変更の差分は、Claude Code の組み込みの `/diff` に任せます
- 日本語などのファイル名も、そのまま読める形で出します（`core.quotePath=false`）。git は index のロックを
  取らずに動かすので（`GIT_OPTIONAL_LOCKS=0`）、Claude が動かす git の邪魔をしません
- 表示している間は 5 秒ごとに状態を確かめ、状態が変わったときと、Claude がコマンドを実行したりファイルを
  編集したりしたときに、全体を読み直します

### コマンドの表示

- `/peek !コマンド` は、ご自身のシェル（`$SHELL`、なければ `/bin/sh`）を対話モードで起動し、作業
  ディレクトリで実行します。エイリアスや関数もそのまま使えます
- 出力はパネルに出し、`!` モードと違って会話には入りません。必要な行だけを引用してください
- 実行を始めるとすぐにパネルが開き、見出しに「実行中…」と出ます。終わると終了コードと、1 秒以上
  かかったときはその秒数を出します。標準エラー出力は分けて出します。色などのエスケープシーケンスは
  取り除きます
- 30 秒で止めます（[設定](#設定)で変えられます）。`tail -f` のように終わらないコマンドには向きません
- `!` モードと同じく、Claude のサンドボックスの外で動きます
- peek は実行するときに `PEEK=1` を渡します。シェルの設定で、Claude Code の中ではエイリアスを切っている
  場合（`CLAUDECODE` を見る書き方）は、`if [[ -z "${CLAUDECODE:-}" || -n "${PEEK:-}" ]]` のように直せば、
  ここではエイリアスが効きます

### ボタンとキー

パネルを開いている間は、入力欄の上に、いま出ている表示のボタンが並びます。クリックするか、この行に
フォーカスを移して（ctrl+x tab かクリック）キーを押します。

| ボタン | 出るとき | キー | 動き |
| --- | --- | --- | --- |
| **ファイル** · **ツリー** · **Git** · **コマンド** | いつも | | 表示を切り替える。それぞれ前の内容を覚えている。初めてのツリーと Git は作業ディレクトリを表示し、ファイルとコマンドは開き方を案内する |
| **選択を引用** | いつも | `q` | パネルで選んだ範囲を、出どころを見出しにして下書きの後ろに足す |
| **ソース** / **整形** | Markdown | `s` | 整形した表示と、行番号付きの書いたままの表示を切り替える |
| **変更 +3 −1** / **変更を閉じる** | ファイルが変わったとき | `d` | 前回の送信からの変更を出す・閉じる |
| **@パス** | ファイル、ツリー | `a` | ファイル（ツリーでは最後にクリックしたフォルダー）を `@` 付きで足し、Claude に読ませる |
| **ツリーを引用** | ツリー | `t` | `tree` と同じ形のツリーを、フォルダーを見出しにしたコードブロックで足す |
| **コミットを入れる** | コミットを開いたとき | `a` | コミットのハッシュと件名を足す |
| **更新** | Git | `r` | Git をすぐに読み直す |
| **出力を引用** | コマンド | `t` | 出力全体を、コマンドを見出しにしたコードブロックで足す |
| **再実行** | コマンド | `r` | コマンドを、前と同じフォルダーでもう一度実行する。終わるまで前の出力を残す |
| **コピー** | ツリー、コマンド | `c` | ツリーか出力をクリップボードに入れる |
| **← 戻る** | リンクやクリックで移ったとき | `b` | 移る前の場所に戻る |
| **閉じる** | いつも | | パネルを閉じる |
| **開く: docs/plan.md** | 返答が `.md` に触れたか、行を示したとき | `o` | 提案されたファイルを、示した行で開く |

引用の行番号は、選んだテキストをファイルの中から探して付けます。ソース表示から選んで行番号が一緒に
入ったときは、その行番号を使います。見つからないとき（画像の代替テキストなど）は、ファイル名だけを
付けます。会話の中で選んだ範囲は、見出しなしで引用します。

### パネル

- 端末が 110 桁以上なら、トランスクリプトの横に 100 桁の幅で表示します（端末の 45% まで。ドラッグで
  変えた幅が優先されます）。それより狭いと入力欄の上に、画面の余裕の範囲で中身の高さに合わせて表示します
- dark 系のテーマでは、パネルの背景を会話の欄と同じ端末の背景にします。ANSI 系のテーマでも明るい文字が
  読みやすいようにするためです
- `/diff` などのほかのタブの後ろにあるときは、`/peek` や帯の表示の切り替えで前に出ます。後ろにある間、帯には
  表示の切り替え、**選択を引用**、**閉じる**だけを出します
- **閉じる**、パネルの閉じるマーク、Esc（パネルにフォーカスがあるときか、入力欄が空で Claude が待機中の
  とき）で閉じます。`/clear` と、別の会話の再開でも閉じます。peek は次の会話で初めからになるためです

## 設定

`/config` に peek の行が 3 つあります。

| 設定 | 値 | 既定値 |
| --- | --- | --- |
| Language | `auto`、`en`、`ja` | `auto`: Claude Code の `language` の設定、次にロケール（`LC_ALL`・`LC_MESSAGES`・`LANG`）、どれもなければ英語 |
| Command time limit (seconds) | 1〜600 | 30 |
| Short commands /tree and /git | オン、オフ | オフ。ほかのプラグインやスキルが使う名前のため。オンにすると `/tree [フォルダー]` と `/git` が `/peek [フォルダー]` と `/peek git` と同じ動きをする |

## 開発

設計は [docs/design.md](docs/design.md) にあります。

```
claude --plugin-dir .            # このフォルダーを読み込んでセッションを始める。保存すると読み直す
claude plugin test .             # tests/*.test.ts(x) を実行する
claude plugin validate .         # マニフェストと hooks module を検査する
```

| ファイル | 中身 |
| --- | --- |
| `hooks/register.tsx` | hooks module。コマンドと、イベントとほかのファイルのつなぎ |
| `hooks/nav.ts` | パネル。開いているか、どの表示か、表示をまたいだ戻る |
| `hooks/views/*.ts` | 表示ごとの状態と、状態を変える操作 |
| `hooks/ui/*.tsx` | パネル、入力欄の上の帯、表示ごとの描画 |
| `hooks/find.ts` | ファイルを探して読む |
| `hooks/prompt.ts` | 入力欄への引用と `@` の追加 |
| `hooks/run.ts` | index のロックを取らない git の実行、時計、表示を読み直す間隔 |
| `hooks/messages.ts` | 英語と日本語のメッセージと、どちらを使うか |
| `hooks/pure/*.ts` | 純粋な関数（パス、引数の解析、引用、Markdown、行の差分、端末の出力、ツリー、git の出力） |
| `tests/*.test.tsx` | エンジンを相手にした mod のテスト。`tests/support.tsx` がその下のエンジン |
| `tests/units.test.ts` | 純粋な関数のテスト |
